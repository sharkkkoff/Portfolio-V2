PROJET PERSONNEL · APPLICATION DESKTOP

Shark Gaming
Hub.

Un launcher que je développe pour regrouper le lancement et le téléchargement de contenus dans une interface unique, avec une attention particulière portée à l’expérience d’utilisation.

ElectronJavaScriptHTML / CSSNode.js

L’IDÉE DE DÉPART

Un outil fait pour répondre à un besoin.

Je voulais créer mon propre environnement pour retrouver et lancer différents contenus sans multiplier les outils. Shark Gaming Hub est donc un projet évolutif, construit autour d’une interface claire et de fonctions que je peux faire évoluer au fil du développement.

Le projet repose sur Electron et les technologies web. Il est conçu pour être distribué sous forme de build portable pour Windows.

FONCTIONNALITÉS

Ce que le launcher regroupe.

01

Téléchargements

Récupération de fichiers depuis des sources distantes, avec une logique de gestion des téléchargements.

02

Lancement

Gestion de paramètres de lancement pour adapter le démarrage des éléments intégrés.

03

Catalogue

Affichage de contenus avec leurs visuels et descriptions pour faciliter leur identification.

04

Données locales

Stockage local pour conserver certaines informations et préférences de l’application.
